HTML Tags Assignment – My School Web Page
Assignment Overview
Create a simple web page about your school using only basic HTML tags.
This assignment focuses on learning and applying common HTML tags to structure and organize content correctly. No CSS or JavaScript should be used.
________________________________________
Learning Objectives
By completing this assignment, students will be able to:
•	Create a complete HTML document
•	Use headings appropriately
•	Create paragraphs and text formatting
•	Insert images
•	Create hyperlinks
•	Use lists
•	Organize content using semantic HTML tags
•	Build a well-structured web page
________________________________________
Required HTML Tags
You must use all of the following tags at least once:
Category	Tags
Document Structure	<html>, <head>, <title>, <body>
Headings	<h1>, <h2>, <h3>
Text Formatting	<p>, <strong>, <em>, <mark>, <br>, <hr>
Lists	<ul>, <ol>, <li>
Links & Media	<a>, <img>
Semantic Tags	<header>, <main>, <section>, <footer>
Additional Tags	<small>, <abbr>
________________________________________
Scenario
Create a web page titled:
“My School – C.W.W. Kannangara College”
The page should introduce your school to a new student.
________________________________________
Assignment Requirements
Section 1 – Page Header
Create a header section containing:
•	School Name using <h1>
•	School Motto using <p>
•	Highlight the motto using <strong>
Example:
<Body>
    <h1>My School</h1>
    <p><strong>Knowledge is Power</strong></p>
</Body>
________________________________________
Section 2 – About the School
Create a section titled:
About Our School
Requirements:
•	Use <h2>
•	Write two paragraphs
•	Use:
o	<em> for an important feeling
o	<mark> for an important fact
________________________________________
Section 3 – School Facilities
Create a section titled:
School Facilities
Requirements:
•	Use <h2>
•	Create an unordered list (<ul>)
•	Include at least 5 facilities
Examples:
•	Computer Laboratory
•	Library
•	Science Laboratory
•	Playground
•	Auditorium
________________________________________
Section 4 – School Rules
Create a section titled:
School Rules
Requirements:
•	Use <h2>
•	Create an ordered list (<ol>)
•	Include at least 5 rules
________________________________________
Section 5 – Clubs and Societies
Create a section titled:
Clubs and Societies
Requirements:
•	Use <h2>
•	Create another unordered list
•	Include at least 5 clubs
Examples:
•	ICT Club
•	AI Club
•	Media Unit
•	Science Society
•	Environmental Club
________________________________________
Section 6 – Principal’s Message
Create a section titled:
Principal’s Message
Requirements:
•	Use <h3>
•	Write one paragraph
•	Include:
o	<strong>
o	<em>
o	<small>
________________________________________
Section 7 – School Image
Requirements:
•	Insert a school image using <img>
•	Include:
o	src
o	alt
o	width
Example:
<img src="school.jpg" alt="School Building" width="400">
________________________________________
Section 8 – School Website
Create a hyperlink to the school website.
Requirements:
•	Use <a>
•	Open in a new tab
Example:
<a href="https://cwwkcc.lk" target="_blank">
Visit Our School Website
</a>
________________________________________
Section 9 – Useful Abbreviation
Use the <abbr> tag.
Example:
<abbr title="Information and Communication Technology">
ICT
</abbr>
________________________________________
Section 10 – Footer
Create a footer containing:
•	Student Name
•	Class
•	Date
Use <small> for all footer information.
________________________________________
Bonus Challenge (10 Marks)
Add:
•	A horizontal line (<hr>) between major sections
•	Line breaks (<br>) where appropriate
•	More than one image
•	Additional abbreviation tags
•	A motivational quote

Sample Page Structure
<!DOCTYPE html>
<html>
<head>
    <title>My School</title>
</head>

<body>

    <!-- Header Content -->

<section>
    <!-- About School -->
</section>

<section>
    <!-- Facilities -->
</section>

<section>
    <!-- Rules -->
</section>

<section>
    <!-- Clubs -->
</section>

<section>
    <!-- Principal Message -->
</section>

</main>

<footer>
    <!-- Student Details -->
</footer>

</body>
</html>
